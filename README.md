# Multi-Agent Cryptographic Key Generator

A full-stack security application that utilizes a multi-agent system to intelligently generate, evaluate, and manage highly secure cryptographic keys. The platform features a robust backend for key generation and a frontend dashboard for credential management and secure storage.

**Live Demo:** [https://cryptominiproject.web.app/](https://cryptominiproject.web.app/)

## ⚙️ How it Works
Users interact with a React-based frontend featuring a Generator Dashboard, Password Vault, and Credential Management interface. The frontend integrates with Firebase for hosting and communicates with a Python backend. The backend operates using a multi-agent architecture where specialized AI and math agents—such as the AI Entropy Agent, Crypto Strength Agent, Math Model Agent, and Performance Agent—collaborate to generate, test, and ensure the cryptographic strength of the keys.

## 🛠 Tech Stack
* **Frontend:** React, Vite, Firebase
* **Backend:** Python (`app.py`), Multi-Agent Architecture
